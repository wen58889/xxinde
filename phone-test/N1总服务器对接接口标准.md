# N1 盒子 - 总服务器对接接口标准

> 文档版本：v2.0
> 更新日期：2026-04-30
> 适用版本：手机自动化测试系统 v2.0（含 TTS+蓝牙+联动+多引擎）

---

## 一、接口概述

### 1.1 通信通道

| 通道 | N1 端口 | 协议 | 用途 |
|------|---------|------|------|
| Moonraker HTTP | 7125 | HTTP | G-code 指令下发、心跳检测、固件重启 |
| go2rtc HTTP | 1984 | HTTP | 按需取帧（JPEG 1280×720） |
| SSH | 22 | SSH/SCP | TTS 音频文件传输 + 远程播放命令 |

### 1.2 N1 需开放的端口

```bash
# 防火墙规则（如有）
ufw allow 7125/tcp   # Moonraker
ufw allow 1984/tcp   # go2rtc
ufw allow 22/tcp     # SSH（TTS 通道）
```

## 二、Moonraker API（端口 7125）

### 2.1 心跳检测

**接口**：`GET /server/info`

```bash
curl -s http://{N1_IP}:7125/server/info
```

**响应**：
```json
{
  "result": {
    "klippy_connected": true,
    "klippy_state": "ready",
    "moonraker_version": "v0.8.0"
  }
}
```

**状态判断**：
| klippy_connected | klippy_state | 含义 |
|-----------------|-------------|------|
| true | ready | 正常，可下发指令 |
| true | error | 固件错误，需 firmware_restart |
| false | — | Klipper 未启动 |

**总控后端使用方式**：
- 心跳间隔：10 秒
- 超时：2 秒
- 1 次失败 → SUSPECT，3 次 → OFFLINE，2 次成功 → 恢复 ONLINE

---

### 2.2 发送 G-code 指令

**接口**：`POST /printer/gcode/script`

```bash
curl -X POST "http://{N1_IP}:7125/printer/gcode/script" \
  -H "Content-Type: application/json" \
  -d '{"script":"G28"}'
```

**总控后端常用 G-code**：

| 指令 | 说明 | 后端调用场景 |
|------|------|-------------|
| `G28` | 归零所有轴 | 前端点"复位"按钮 |
| `G1 Z3 F3000` | 抬起 Z 到安全高度 | 每次点击/滑动前 |
| `G1 Xnn Ynn F6000` | 移动 XY | tap/long_press/swipe |
| `G1 Z-1.0 F6000` | Z 下压点击 | tap 动作 |
| `G4 P500` | 延时 500ms | long_press 等待 |
| `G1 Y0 F3000` | Y 轴归位（让摄像头避开屏幕） | park_y，每次截图前 |
| `M112` | 紧急停止 | 前端点"紧急停止" |
| `FIRMWARE_RESTART` | 重启固件 | 紧停后恢复 |

> **注意**：F 参数单位为 mm/min。F9000 = 150mm/s，F6000 = 100mm/s

---

### 2.3 紧急停止与恢复

**紧停流程**：
```
前端点击急停
  → POST /printer/emergency_stop
  → 设备状态标记 ESTOP
  → Klipper 进入 Shutdown 状态
```

**恢复流程**：
```
前端点"复位"按钮
  → POST /printer/firmware_restart
  → 等待 Klipper 恢复 ready 状态
  → 设备状态恢复 ONLINE
```

---

### 2.4 查询设备状态

**接口**：`GET /printer/objects/query?print_stats&toolhead&gcode_move`

```bash
curl -s "http://{N1_IP}:7125/printer/objects/query?print_stats=state&toolhead=position&gcode_move=position"
```

## 三、截图服务 API（端口 1984）

**接口**：`GET /api/streams/camera0.jpg`

```bash
curl -o /tmp/screenshot.jpg "http://{N1_IP}:1984/api/streams/camera0.jpg"
```

**总控后端调用流程**：
```
需要截图时
  → 先 POST G1 Z3 + G1 Y0 (park_y，移开摄像头)
  → 等待 500ms
  → GET /api/streams/camera0.jpg
  → 返回 JPEG (1280×720)
  → 送入视觉识别（模板匹配/OCR）
```

## 四、SSH 通道 — TTS 语音播放（端口 22）

### 4.1 通信流程

```
总控后端收到 TTS 请求
  → Edge TTS / 腾讯云 合成 MP3
  → 保存到 static/tts/tts_xxx.mp3
  → SSH 连接 N1 (root/1234)
  → SCP 传输 MP3 到 N1 /tmp/phone_tts/
  → 执行播放命令
  → 播完自动删除临时文件
```

### 4.2 播放命令

**优先链路**（PulseAudio + 蓝牙音箱可用时）：
```bash
mpg123 -o pulse '/tmp/phone_tts/tts_xxx.mp3'
# → PulseAudio → A2DP → 蓝牙音箱出声
```

**降级链路**（PulseAudio 不可用时）：
```bash
ffplay -nodisp -autoexit -loglevel quiet '/tmp/phone_tts/tts_xxx.mp3'
# → 板载声卡 3.5mm 接口出声
```

### 4.3 N1 端音频设备

| 设备 | PulseAudio sink | 用途 |
|------|----------------|------|
| 板载声卡 (ALSA) | alsa_output.platform-sound... | 降级播放 |
| 蓝牙音箱 (A2DP) | bluez_sink.XX_XX_...a2dp_sink | 主要播放（默认） |

### 4.4 总控后端配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| N1_SSH_USER | root | SSH 用户名 |
| N1_SSH_PASSWORD | 1234 | SSH 密码 |
| N1_AUDIO_PLAYER | ffplay | 降级播放器（实际优先走 PulseAudio） |

## 五、总控服务器 API（后端 8080）

### 5.1 设备管理

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/devices` | GET | 列出所有设备及状态 |
| `/api/v1/devices/{id}/home` | POST | 发送 G28 归零 |
| `/api/v1/devices/{id}/estop` | POST | 紧急停止 |
| `/api/v1/devices/{id}/reset` | POST | 紧停恢复（firmware_restart） |
| `/api/v1/devices/{id}/tap_pixel` | POST | 联动点击（XY+Z+parkY+刷新图像） |
| `/api/v1/devices/{id}/park_y` | POST | Y 轴归位（摄像头避开屏幕） |

### 5.2 TTS 语音合成

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/tts/synthesize` | POST | 合成语音并在 N1 设备播放 |
| `/api/v1/tts/status` | GET | 查询 TTS 配置状态 |

**TTS 请求**：
```json
POST /api/v1/tts/synthesize
{
  "text": "请点击确认按钮",
  "voice_type": 1001,
  "device_id": 1
}
```

**TTS 响应**：
```json
{
  "text": "请点击确认按钮",
  "audio_url": "/static/tts/tts_1777528504326.mp3",
  "duration_ms": 1242,
  "engine": "edge",
  "played_on": "192.168.5.101"
}
```

**TTS 引擎**：

| 引擎 | 配置 | 说明 |
|------|------|------|
| edge | 免费免配置（默认） | 微软 Edge 在线 TTS，音质好 |
| tencent | 需 SecretId/SecretKey | 腾讯云 TTS (API v2019-08-23) |
| aliyun | 需 AccessKeyId/Secret | 阿里云 TTS |
| microsoft | 需 API Key + Region | 微软 Azure TTS |
| custom | 需服务器 URL | 自定义局域网 TTS |

### 5.3 自动脚本执行

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/tasks` | GET | 列出任务 |
| `/api/v1/tasks` | POST | 创建执行任务（YAML 脚本） |

**YAML 脚本支持的 action**：

| action | 说明 | 关键参数 |
|--------|------|---------|
| `tap_icon` | 视觉识别+点击 | text, template, threshold |
| `tap` | 按屏幕百分比点击 | screen_percent: [x, y] |
| `tap_text` | OCR 识别文字+点击 | keyword |
| `long_press` | 长按 | screen_percent, seconds |
| `swipe_up/down/left/right` | 滑动 | start_percent, end_percent, duration_ms |
| `detect_state` | 检测页面状态 | templates, ocr_keywords, timeout |
| `detect_anomaly` | 检测异常 | — |
| `tts` | 语音播报 | text, voice_type |
| `wait` | 等待 | seconds |

**TTS action 在脚本中的用法**：
```yaml
steps:
  - action: tts
    text: "请点击确认按钮"
    voice_type: 1001
    wait: 2
```

### 5.4 联动功能

前端开启"联动"后，点击预览图上的位置会：
```
前端点击像素坐标
  → 后端 tap_pixel API
  → park_y（移开摄像头）
  → 移动 XY 到对应机械坐标
  → Z 下压点击
  → Z 抬起
  → park_y（归位）
  → 等待 500ms
  → 刷新摄像头图像
```

## 六、完整通信流程

### 6.1 联动点击流程

```
1. 前端点击图像 → 总控后端 tap_pixel(pixel_x, pixel_y)
2. → park_y (POST G1 Y0) → 截图前摄像头避让
3. → 移动 XY (POST G1 Xx Yy F6000)
4. → 下压 Z (POST G1 Z-1.0 F6000)
5. → 抬起 Z (POST G1 Z3 F3000)
6. → park_y → 等待 500ms → 刷新图像
```

### 6.2 自动脚本执行流程

```
1. 加载 YAML 脚本 → 按步骤执行
2. 每步: park_y → 截图 → 视觉识别 → 机械操作
3. TTS 步骤: 合成 MP3 → SSH 传输 → N1 播放 → 蓝牙音箱出声
4. 异常: 自动抬 Z → 记录错误 → 继续/停止
5. 完成: park_y → 摄像头归位
```

### 6.3 紧停恢复流程

```
1. 前端点急停 → POST /printer/emergency_stop
2. → Klipper 进入 Shutdown 状态
3. → 设备标记 ESTOP
4. 复位: POST /printer/firmware_restart
5. → 等待 klippy_state = ready
6. → 刷新设备列表
```

## 七、错误处理

### 7.1 通信错误

| 错误 | 处理 |
|------|------|
| Moonraker 连接超时 | 标记 SUSPECT → 3 次后 OFFLINE |
| HTTP 500 | 记录错误，跳过当前步骤 |
| 拍照失败/超时 (>8s) | 重试 1 次，失败则告警 |
| SSH 连接失败 | 仅 log warning，TTS 不中断流程 |

### 7.2 运动错误

| 错误 | 处理 |
|------|------|
| Z 轴 Move out of range | 自动 fallback 到 Z=0.05，不报错 |
| 步骤执行异常 | 自动抬 Z 到安全高度，记录错误 |
| 紧急停止 | Klipper Shutdown，等待人工 firmware_restart |
| TTS 合成失败 | ValueError 跳过，其他错误记录，不中断脚本 |

## 八、设备自动发现

总控后端启动时，自动扫描 `DEVICE_IP_START` ~ `DEVICE_IP_END` 范围内的设备。

**配置（.env）**：
```env
DEVICE_IP_START=192.168.5.101
DEVICE_IP_END=192.168.5.200
DEVICE_MOONRAKER_PORT=7125
DEVICE_CAMERA_PORT=1984
```

**扫描逻辑**：
- 心跳间隔 10 秒，最大并发 15 台
- 对每台 IP 发 `GET /server/info`（2s 超时）
- 成功 → ONLINE，失败累计 → OFFLINE
- 新发现的 IP 自动入库（数据库 Device 表）
