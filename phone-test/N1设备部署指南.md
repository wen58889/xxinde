# N1 设备部署指南 — 接入手机自动化测试系统

> 本文档指导在新 N1 设备上安装所有必要软件，配对蓝牙音箱，并接入总控服务器。
> 适用于批量生产场景，所有 N1 设备配置相同。

---

## 1. 前置条件

| 项目 | 要求 |
|------|------|
| N1 设备系统 | Armbian Debian 13 (aarch64)，SSH 可达 |
| SSH 账号 | `root` / `1234`（默认） |
| 网络 | N1 与总控服务器在同一局域网（如 192.168.5.x） |
| Klipper + Moonraker | 已安装并运行（端口 7125） |
| go2rtc | 已安装并运行（端口 1984，摄像头截图） |
| 蓝牙音箱 | 已充电开机，在 N1 蓝牙覆盖范围内 |

---

## 2. N1 设备软件安装（一键脚本）

SSH 登录 N1 设备后，执行以下命令：

```bash
# ========== 2.1 更新系统 ==========
apt-get update && apt-get upgrade -y

# ========== 2.2 安装蓝牙协议栈 ==========
apt-get install -y bluez bluez-tools

# ========== 2.3 安装 PulseAudio + 蓝牙音频模块 ==========
apt-get install -y pulseaudio pulseaudio-module-bluetooth pulseaudio-utils

# ========== 2.4 安装音频播放器 ==========
apt-get install -y mpg123 ffmpeg

# ========== 2.5 配置 PulseAudio ==========
mkdir -p /etc/pulse
cat > /etc/pulse/daemon.conf << 'EOF'
resample-method = trivial
default-sample-rate = 48000
EOF

# ========== 2.6 启动蓝牙服务 ==========
systemctl enable bluetooth
systemctl start bluetooth

# ========== 2.7 启动 PulseAudio ==========
pulseaudio --start || pulseaudio -D --fail=quiet
```

## 3. 蓝牙音箱配对

### 3.1 扫描蓝牙设备

```bash
# 开启蓝牙适配器
bluetoothctl power on

# 扫描 10 秒，记下你的蓝牙音箱 MAC 地址
bluetoothctl --timeout 10 scan on

# 查看发现的设备
bluetoothctl devices
```

输出示例：
```
Device 00:12:6F:B3:3B:2A Beoplay A1
Device 50:5A:65:98:24:53 XIAOYU
```

### 3.2 配对并连接

将 `XX:XX:XX:XX:XX:XX` 替换为你的蓝牙音箱 MAC 地址：

```bash
# 信任（允许自动重连）
bluetoothctl trust XX:XX:XX:XX:XX:XX

# 配对
bluetoothctl pair XX:XX:XX:XX:XX:XX

# 连接
bluetoothctl connect XX:XX:XX:XX:XX:XX
```

### 3.3 验证连接

```bash
bluetoothctl info XX:XX:XX:XX:XX:XX
```

确认输出中：
- `Paired: yes`
- `Trusted: yes`
- `Connected: yes`
- 包含 `Audio Sink` UUID

### 3.4 设置蓝牙音箱为默认音频输出

```bash
# 查看所有音频输出设备
pactl list sinks short

# 输出类似：
# 0  alsa_output.platform-sound...    module-alsa-card.c     ...
# 1  bluez_sink.XX_XX_XX_XX_XX_XX.a2dp_sink  module-bluez5-device.c  ...

# 设置蓝牙音箱为默认（编号 1 是蓝牙）
pactl set-default-sink 1

# 设置音量 75%
pactl set-sink-volume @DEFAULT_SINK@ 75%
```

## 4. 配置开机自启（自动连接蓝牙音箱）

### 4.1 创建连接脚本

> **重要**：将 `XX:XX:XX:XX:XX:XX` 替换为你的蓝牙音箱 MAC 地址
> **批量生产**：所有 N1 使用同一型号蓝牙音箱时，MAC 不同，需每台单独配对后修改此脚本

```bash
cat > /usr/local/bin/bt-speaker-connect.sh << 'EOF'
#!/bin/bash
# Auto-connect Bluetooth speaker and set as default audio output
pulseaudio --start 2>/dev/null || pulseaudio -D --fail=quiet 2>/dev/null
sleep 2
echo -e "power on\nconnect XX:XX:XX:XX:XX:XX" | bluetoothctl
sleep 5
SINK=$(pactl list sinks short 2>/dev/null | grep bluez | head -1 | awk '{print $2}')
if [ -n "$SINK" ]; then
  pactl set-default-sink "$SINK" 2>/dev/null
  pactl set-sink-volume @DEFAULT_SINK@ 75% 2>/dev/null
fi
EOF

chmod +x /usr/local/bin/bt-speaker-connect.sh
```

### 4.2 创建 systemd 服务

```bash
cat > /etc/systemd/system/bt-speaker.service << 'EOF'
[Unit]
Description=Auto-connect Bluetooth speaker
After=bluetooth.service
Wants=bluetooth.service

[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=/usr/local/bin/bt-speaker-connect.sh

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable bt-speaker.service
```

### 4.3 验证

```bash
systemctl is-enabled bt-speaker.service
# 应输出: enabled
```

## 5. 测试音频播放

### 5.1 测试板载声卡

```bash
aplay /usr/share/sounds/alsa/Front_Left.wav
```

### 5.2 测试蓝牙音箱（通过 PulseAudio）

```bash
# WAV 文件
paplay /usr/share/sounds/alsa/Front_Left.wav

# MP3 文件（mpg123 走 PulseAudio）
mpg123 -o pulse /path/to/test.mp3
```

> 蓝牙音箱应发出声音。如果无声，检查：
> 1. `pactl list sinks short` 是否有 bluez sink
> 2. 蓝牙音箱是否已配对连接
> 3. PulseAudio 是否在运行（`pgrep pulseaudio`）

## 6. 总控服务器端配置

### 6.1 确认 N1 设备在扫描范围内

编辑总控服务器 `.env` 文件（`phone-test/backend/.env`），确保 `DEVICE_IP_START` 和 `DEVICE_IP_END` 覆盖新 N1 的 IP：

```env
DEVICE_IP_START=192.168.5.101
DEVICE_IP_END=192.168.5.200
```

### 6.2 N1 SSH 配置

所有 N1 设备使用统一的 SSH 账号（已在 `.env` 中配置）：

```env
N1_SSH_USER=root
N1_SSH_PASSWORD=1234
N1_AUDIO_PLAYER=ffplay
```

> `N1_AUDIO_PLAYER` 仅作为降级播放器。代码会自动检测 PulseAudio + 蓝牙 sink，
> 优先使用 `mpg123 -o pulse` 走蓝牙音箱，PulseAudio 不可用时才降级到 ffplay。

### 6.3 重启总控服务器

```bash
# 重启后端让配置生效
# 总控服务器会自动扫描新 IP 范围内的设备
```

## 7. 完整音频播放链路

```
前端发送TTS请求
  → 总控后端 Edge TTS 合成 MP3
  → 保存到 static/tts/ 目录
  → SSH 连接 N1 设备
  → SCP 传输 MP3 到 N1 /tmp/phone_tts/
  → mpg123 -o pulse 播放
  → PulseAudio 路由到蓝牙 sink
  → A2DP 协议发送到蓝牙音箱
  → 蓝牙音箱出声
  → 播完后自动删除临时文件
```

降级链路（PulseAudio 不可用时）：
```
  → ffplay 播放（走板载声卡 3.5mm 接口）
```

## 8. 批量生产部署流程

### 8.1 每台 N1 出厂前需要做

1. **烧录系统镜像** — Armbian Debian 13 + Klipper + Moonraker + go2rtc
2. **配置网络** — 设置静态 IP（如 192.168.5.101/102/103...）
3. **执行第 2 步** — 安装所有软件包
4. **配对蓝牙音箱** — 执行第 3 步（每台音箱 MAC 不同，需逐台配对）
5. **配置开机自启** — 执行第 4 步（脚本中写入该台音箱的 MAC）
6. **测试** — 执行第 5 步验证音频播放

### 8.2 批量部署脚本（可自动化）

将以下脚本保存为 `n1_setup.sh`，在每台 N1 上执行：

```bash
#!/bin/bash
# N1 设备批量部署脚本
# 用法: ./n1_setup.sh <蓝牙音箱MAC>
# 示例: ./n1_setup.sh 00:12:6F:B3:3B:2A

BT_MAC=${1:?用法: $0 <蓝牙音箱MAC地址>}

set -e

echo "[1/6] 更新系统..."
apt-get update && apt-get upgrade -y

echo "[2/6] 安装软件包..."
apt-get install -y bluez bluez-tools \
  pulseaudio pulseaudio-module-bluetooth pulseaudio-utils \
  mpg123 ffmpeg

echo "[3/6] 配置 PulseAudio..."
mkdir -p /etc/pulse
cat > /etc/pulse/daemon.conf << 'PAEOF'
resample-method = trivial
default-sample-rate = 48000
PAEOF

echo "[4/6] 启动服务..."
systemctl enable bluetooth
systemctl start bluetooth
pulseaudio --start 2>/dev/null || pulseaudio -D --fail=quiet 2>/dev/null
sleep 2

echo "[5/6] 配对蓝牙音箱 $BT_MAC ..."
bluetoothctl power on
bluetoothctl trust "$BT_MAC"
bluetoothctl pair "$BT_MAC"
bluetoothctl connect "$BT_MAC"

echo "[6/6] 配置开机自启..."
cat > /usr/local/bin/bt-speaker-connect.sh << BTEOF
#!/bin/bash
pulseaudio --start 2>/dev/null || pulseaudio -D --fail=quiet 2>/dev/null
sleep 2
echo -e "power on\nconnect $BT_MAC" | bluetoothctl
sleep 5
SINK=\$(pactl list sinks short 2>/dev/null | grep bluez | head -1 | awk '{print \$2}')
if [ -n "\$SINK" ]; then
  pactl set-default-sink "\$SINK" 2>/dev/null
  pactl set-sink-volume @DEFAULT_SINK@ 75% 2>/dev/null
fi
BTEOF
chmod +x /usr/local/bin/bt-speaker-connect.sh

cat > /etc/systemd/system/bt-speaker.service << SVCEOF
[Unit]
Description=Auto-connect Bluetooth speaker
After=bluetooth.service
Wants=bluetooth.service

[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=/usr/local/bin/bt-speaker-connect.sh

[Install]
WantedBy=multi-user.target
SVCEOF
systemctl daemon-reload
systemctl enable bt-speaker.service

echo ""
echo "==============================="
echo "  N1 部署完成！"
echo "  蓝牙音箱: $BT_MAC"
echo "==============================="
echo ""
echo "验证步骤："
echo "  1. bluetoothctl info $BT_MAC  # 确认 Connected: yes"
echo "  2. pactl list sinks short     # 确认有 bluez sink"
echo "  3. mpg123 -o pulse test.mp3   # 确认音箱出声"
```

### 8.3 从总控服务器远程部署

在总控服务器上，可通过 SSH 远程执行部署脚本：

```bash
# 将部署脚本发送到 N1
scp n1_setup.sh root@192.168.5.102:/tmp/

# 远程执行（替换为实际蓝牙音箱 MAC）
ssh root@192.168.5.102 "bash /tmp/n1_setup.sh 00:12:6F:B3:3B:2A"
```

## 9. 故障排查

| 问题 | 检查命令 | 解决方案 |
|------|---------|---------|
| 蓝牙服务未运行 | `systemctl status bluetooth` | `systemctl start bluetooth` |
| 找不到蓝牙适配器 | `hciconfig` | 检查硬件/内核模块 `lsmod \| grep bluetooth` |
| 蓝牙音箱未连接 | `bluetoothctl info XX:XX` | `bluetoothctl connect XX:XX` |
| PulseAudio 未运行 | `pgrep pulseaudio` | `pulseaudio --start` |
| 无蓝牙 sink | `pactl list sinks short` | 安装 `pulseaudio-module-bluetooth` 并重启 PA |
| mpg123 无声 | `mpg123 -o pulse test.mp3` | 确认默认 sink 是蓝牙 `pactl set-default-sink 1` |
| SSH 连接失败 | `ssh root@N1_IP` | 检查网络、密码、SSH 服务 |
| TTS 合成失败 | 看后端日志 | 检查 `edge-tts` 包是否安装 |
