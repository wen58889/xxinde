## 一、部署完成检查清单

| 服务 | 端口 | 用途 | 验证命令 |

## 四、蓝牙音箱配置

| 项目 | 值 |
|------|-----|
| 音箱型号 | Beoplay A1（B&O） |
| MAC 地址 | 00:12:6F:B3:3B:2A（每台音箱不同） |
| 协议 | A2DP (Advanced Audio Distribution Profile) |
| PulseAudio sink | bluez_sink.00_12_6F_B3_3B_2A.a2dp_sink |
| 默认音量 | 75% |
| 自动重连 | ✅ bt-speaker.service (enabled) |

### 音频播放链路

```
总控 TTS 合成 MP3
  → SSH scp 到 N1 /tmp/phone_tts/
  → mpg123 -o pulse 播放
  → PulseAudio 路由到蓝牙 sink
  → A2DP 协议 → 蓝牙音箱出声
  → 播完自动删除临时文件
```

降级链路（PulseAudio 不可用时）：
```
  → ffplay 播放（走板载声卡 3.5mm 接口）
```

## 八、快速命令参考

```bash
# === 服务管理 ===
systemctl status klipper moonraker go2rtc bluetooth
systemctl restart klipper moonraker go2rtc

# === 蓝牙 ===
bluetoothctl devices                    # 列出已配对设备
bluetoothctl info XX:XX:XX:XX:XX:XX    # 查看连接状态
bluetoothctl connect XX:XX:XX:XX:XX:XX # 手动连接

# === 音频 ===
pactl list sinks short                 # 查看音频输出设备
pactl set-default-sink 1               # 设置蓝牙为默认输出
pactl set-sink-volume @DEFAULT_SINK@ 75%  # 设置音量
mpg123 -o pulse /tmp/test.mp3          # 测试蓝牙播放

# === G-code ===
curl -X POST http://localhost:7125/printer/gcode/script \
  -H "Content-Type: application/json" -d '{"script":"G28"}'

# === 拍照 ===
curl -o /tmp/shot.jpg http://localhost:1984/api/frame.jpeg?src=camera0

# === 日志 ===
journalctl -u moonraker -f
journalctl -u klipper -f
journalctl -u bt-speaker -f
```

## 九、验证全部就绪

```bash
echo "=== 服务状态 ==="
for svc in klipper moonraker go2rtc bluetooth; do
  s=$(systemctl is-active $svc 2>/dev/null)
  echo "$svc: $s"
done

echo ""
echo "=== 蓝牙音箱 ==="
pactl list sinks short 2>/dev/null | grep bluez && echo "蓝牙sink: OK" || echo "蓝牙sink: 未连接"

echo ""
echo "=== PulseAudio ==="
pgrep pulseaudio > /dev/null && echo "PulseAudio: 运行中" || echo "PulseAudio: 未运行"

echo ""
echo "=== Moonraker ==="
curl -s http://localhost:7125/server/info | grep -o '"klippy_connected": true' && echo "Klipper: 已连接" || echo "Klipper: 未连接"

echo ""
echo "=== 拍照 ==="
curl -s -o /tmp/verify.jpg http://localhost:1984/api/frame.jpeg?src=camera0 && echo "拍照: OK ($(stat -c%s /tmp/verify.jpg) bytes)" || echo "拍照: 失败"
```
